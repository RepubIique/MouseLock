Mouse Lock

A tiny menu bar app that keeps your cursor on one display. Built for presenters using ProPresenter, Keynote, or any extended-desktop setup.

Download latest release ☕ Buy me a coffee View on GitHub

Features

  • Lock the cursor to any connected display
  • Toggle with ⌃ ⌥ L or from the menu bar
  • Optional wrap-around at screen edges
  • Runs from the menu bar — no Dock icon
  • Auto-detects when displays are plugged in or removed

Install

  1. Download MouseLock.zip from the latest GitHub release.
  2. Unzip and drag MouseLock.app into Applications.
  3. Open it — if macOS blocks it, right-click → Open → Open again.
  4. Click the display icon in the menu bar, pick your screen, and lock.

Build from source

  1. Clone the repo and open MouseLock.xcodeproj in Xcode.
  2. Press ⌘ R to run. Requires macOS 13+.
